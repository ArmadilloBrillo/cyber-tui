---
name: No code snippets during implementation
description: User does not want to see code snippets or diffs while Claude implements changes
type: feedback
---

Do not show code snippets or diffs while implementing. Just describe what you're doing in plain prose and report results (test output, errors, etc.).

**Why:** User preference — they find inline code blocks during implementation noisy and unnecessary.

**How to apply:** During any implementation phase, narrate actions in plain text ("Adding X to Y", "Fixing Z in file F") without showing the actual code. Show test results and error output as needed.
